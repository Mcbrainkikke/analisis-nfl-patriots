# 🏈 Análisis de datos NFL — New England Patriots

Análisis estadístico e histórico de los New England Patriots usando Python,
trabajando con datos reales de partidos desde 1971 hasta 2026.

---

## 🗂️ Descripción del proyecto

Este proyecto analiza el rendimiento histórico de los New England Patriots
usando el dataset de NFL scores and betting data de Kaggle. El análisis
incluye resultados por temporada, rendimiento local vs visitante y
comparación de quarterbacks.

---

## 🛠️ Tecnologías utilizadas

- Python 3.12
- pandas
- matplotlib

---

## 📈 Análisis realizados

- Carga y limpieza de datos
- Filtrado de partidos de los Patriots (921 partidos)
- Resultados históricos: 531 victorias y 390 derrotas
- (En progreso) Rendimiento por temporada
- (En progreso) Comparación Brady vs Drake Maye
